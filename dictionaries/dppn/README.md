# Dictionary of Pāli Proper Names (DPPN)

G. P. Malalasekera's Dictionary of Pāli Proper Names, revised by Ānandajoti Bhikkhu.

## Source

- `source/DPPN.json` - JSON dictionary data

## Run

```bash
uv run python -m dictionaries.dppn.dppn
```

## Output

- `build/goldendict/dppn.zip`
- `build/mdict/dppn.mdx.zip`
