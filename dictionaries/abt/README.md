# Ancient Buddhist Texts Glossary (CPED)

Concise Pali English Dictionary from Ven. Ānandajoti's Ancient Buddhist Texts.

## Source

- `source/CPED.csv` - Pipe-delimited CSV file

## Run

```bash
uv run python -m dictionaries.abt.abt_glossary
```

## Output

- `build/goldendict/cped.zip`
- `build/mdict/cped.mdx.zip`
