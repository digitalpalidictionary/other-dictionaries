# Sinhala-English-Sinhala Dictionary

Trilingual dictionary from University of Colombo School of Computing.

## Source

- `source/english-sinhala.tab` - English to Sinhala
- `source/sinhala-english.tab` - Sinhala to English

## Run

```bash
uv run python -m dictionaries.sin_eng_sin.sin_eng_sin
```

## Output

- `build/goldendict/si-en-si.zip`
- `build/mdict/si-en-si.mdx.zip`
