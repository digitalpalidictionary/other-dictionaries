# Whitney Sanskrit Roots

The Roots, Verb-Forms and Primary Derivatives of the Sanskrit Language by William Dwight Whitney (1895).

## Source

- `source/*.xml` - XML files from Cologne Sanskrit Lexicon

## Run

```bash
uv run python -m dictionaries.whitney.whitney
```

## Output

- `build/goldendict/whitney.zip`
- `build/mdict/whitney.mdx.zip`
