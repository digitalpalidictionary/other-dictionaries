# Dictionary of Pāli by Margaret Cone

A comprehensive Pāli-English dictionary (volumes I-III).

## Source

- `source/cone_dict.json` - Main dictionary entries
- `source/cone_front_matter.json` - Front matter entries

## Run

```bash
uv run python -m dictionaries.cone.cone
```

## Output

- `build/goldendict/cone.zip`
- `build/mdict/cone.mdx.zip`
