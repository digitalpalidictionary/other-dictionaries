# Buddhist Hybrid Sanskrit Dictionary

Edgerton's Buddhist Hybrid Sanskrit grammar and dictionary (1953).

## Source

- `source/bhs.xml` - XML file from Cologne Sanskrit Lexicon

## Run

```bash
uv run python -m dictionaries.bhs.bhs
```

## Output

- `build/goldendict/bhs.zip`
- `build/mdict/bhs.mdx.zip`
